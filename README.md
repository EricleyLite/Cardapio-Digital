# 🍽️ Cardápio Digital - Le Cheff Ristorant

Um cardápio web interativo e responsivo desenvolvido para o **Le Cheff Ristorant**, apresentando uma galeria de pratos com design moderno e efeitos de iluminação e transição.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da aplicação web.
- **CSS3**: Estilização visual, uso de Flexbox para layout flexível, efeitos de hover (`transform: scale`) e sombras.

---

## ✨ Funcionalidades

- **Galeria Flexível**: Organização dos pratos utilizando Flexbox (`display: flex` e `flex-wrap: wrap`), permitindo adaptação em diferentes tamanhos de tela.
- **Efeito Interativo**: Efeito suave de zoom (`transform: scale(1.1)`) ao passar o ponteiro do mouse sobre cada item do cardápio.
- **Design Temático**: Paleta de cores aconchegante e tipografia personalizada para restaurante.

   ```bash

   ```
